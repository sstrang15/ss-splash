# ss-splash

A temporary public landing experience for stephenstrang.com while the full SS-site is under construction.

## Overview

ss-splash is a small, standalone web project built with HTML, CSS, and JavaScript.

The experience uses a minimal code-inspired interface with animated text, typing audio, external links, and an email signup for project updates.
